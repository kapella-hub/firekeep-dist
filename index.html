Firekeep — client distribution

Release artifacts for the Firekeep client kit. This host serves checksum-verified wheels and bootstrap scripts; it contains no product source.

# macOS / Linux
curl -fsSL https://kapella-hub.github.io/firekeep-dist/latest/install.sh | sh

# Windows (PowerShell)
irm https://kapella-hub.github.io/firekeep-dist/latest/install.ps1 | iex

Every artifact is listed with its SHA-256 in <version>/SHA256SUMS. The bootstrap verifies both the toolchain and the wheel against it before either is executed.
